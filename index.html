Part A: Node.js HTTP Server

Welcome to Employee Management System

This application is built using core Node.js built-in HTTP and FS modules without using external frameworks. It demonstrates raw HTTP request handling, static file serving, and JSON API routing.

Available Endpoints:

  • GET / - Welcome Page (HTML)
  • GET /employees - View all employees (JSON)
  • GET /about - Application details & developer info (HTML)
  • POST /add-employee - Add a new employee (JSON payload)
