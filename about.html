About This Application

This Employee Management System was created for the Full Stack Development (FSD) Lab Exam (MT-1).

Course: Full Stack Development (FSD)

Module: Part A - Node.js HTTP Server

Technologies: Node.js (v24), Built-in HTTP Module, Built-in File System (FS) Module

Storage: In-Memory JavaScript Array (No database required)

The server listens for incoming HTTP requests, analyzes the request URL and method, and either streams HTML files from disk using fs.readFile() or responds with JSON.
